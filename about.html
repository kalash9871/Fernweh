About TripCraft & Academic Architecture

An individual BCA 5th Semester Web Application Development Capstone Project dedicated to empowering mindful exploration of India's hidden gems.

Vision & Sustainable Travel Philosophy

Mainstream tourism in India remains heavily concentrated in congested commercial spots—straining delicate Himalayan passes, fragile river eco-zones, and coastal ecosystems. TripCraft was conceived to champion 9 authentic offbeat destinations—from the Apatani villages of Ziro Valley to the river Satras of Majuli and the medieval stone architecture of Orchha.

By connecting travelers with local homestays, indigenous guides, and practical day-wise itineraries, TripCraft shifts travel spending directly into grassroots economies while offering travelers deeper, unhurried cultural immersion.

Promotes Sustainable Tourism Encourages respectful visits to indigenous tribal cultures and eco-villages.
Transparent Destination-Based Costing Realistic models accounting for twin-sharing rooms, cab pooling, and authentic regional dining.
Clean & Viva-Ready Architecture Pure HTML5, CSS3, Vanilla JS, and lightweight Python Flask backend with REST APIs.

Viva Presentation Guide — Key Architectural Highlights

1. Why Use Flask to Serve the Frontend Directly?

Serving the frontend static assets directly via Flask eliminates Cross-Origin Resource Sharing (CORS) complexity and allows the complete application to launch with a single terminal command: python backend/app.py.

2. How Does Destination-Based Budgeting Work?

Rather than arbitrary percentage allocations, each destination defines realistic baseline room costs, regional dining rates, and transit fares. Lodging scales on twin-sharing (ceil(travellers/2)) and local cab costs scale per 4 passengers.

3. How is Input Validation Handled?

Both frontend (client-side instantaneous feedback) and backend (server-side HTTP 400 enforcement) validate boundaries: days between 1-14, minimum budget ₹1,000, travellers between 1-20, and valid destination identifiers.

4. Why Vanilla JS Instead of React or Vue?

For an individual BCA semester project, Vanilla JS (ES6+) demonstrates fundamental mastery of the DOM, event handling, async/await Fetch API, and CSS transitions without external bundle bloat or build-step dependencies.
